# Anomalous interval detection

The detector compares short intervals of normal forecast pseudo-residuals with a
common reference generated by a fitted HMM. It implements the interval method in
the Variance manuscript: lag histories, reference whitening, a regularized Gaussian
KL score, independent whole-search simulation calibration, and optimal selection
of non-overlapping intervals. It works with any number of response channels and
both discrete-time and continuous-time HMMs. No empirical data or fitted models
are supplied.

## Quick example

Requires Julia 1.10 or later. The public release includes the default Julia 1.10
manifest and a separate `Manifest-v1.13.toml`, selected automatically by Julia 1.13
to account for its standard-library versions. Instantiate the project once, then
run the example and tests from the repository root:

```sh
julia --project=. -e 'using Pkg; Pkg.instantiate()'
julia --project=. examples/anomalous-intervals.jl
julia --project=. test/runtests.jl
```

The example specifies a small two-state Normal HMM, simulates an independent
reference bank and calibration bank, adds a departure to a synthetic observation
sequence, computes forecast residuals, and reports the selected interval. It does
not fit a model, read research files, or write results. Paths inside the script
are relative to the script, so it can also be run from another working directory
with an absolute `--project` and script path.

## Pipeline and API

1. Define an `HMMIntervalDesign` for each observation sequence. `n` is the number
   of observations. `segments` contains ordered, disjoint ranges of usable
   observation positions. Specify separate segments at gaps or monitoring breaks;
   the detector does not infer a sampling rate, interpolate gaps, or drop a whole
   trip because it contains a gap. For a CTHMM, supply the actual `n-1` elapsed
   times and pass `continuous_time=true` throughout the pipeline.
2. Call `HMM_interval_reference(designs, responses, transition, initial, states)`.
   Each simulated trip samples one eligible design uniformly. The latent path is
   discarded, observations are filtered with the existing HMMToolkit functions,
   and all usable lag histories are pooled to estimate common moments. Default:
   500 trips and `q=1`. The pooled reference covariance uses divisor `N-1`.
3. Call `HMM_calibrate_interval_penalty(design, responses, transition, initial,
   states, bank.reference; lengths=...)` using a separate simulation bank.
   Every replicate preserves the design and repeats the complete interval scan.
   Default: 1,999 replicates and a prespecified whole-search level `alpha=0.05`.
4. Call `HMM_interval_residuals` on the observed trip. This reuses the existing
   emission precomputations and normal forecast pseudo-residual functions; it
   does not decode or use latent states.
5. Call `HMM_detect_intervals(prepared.residuals, calibration)`. Calibration
   supplies the reference, lengths, usable ranges, and penalty, avoiding accidental
   changes to the search design between calibration and detection.

`DTHMM_sim_time_series` and `CTHMM_sim_time_series` gain overloads accepting the
design as a fifth positional argument and a `response_list` keyword. Their
original convenience methods remain available. Emissions use the package's
existing `sim_expert` methods. Use `Random.seed!` before each bank for reproducible
runs; record the seed, model identity, design, and calibration object in calling
code. Independent banks use fresh draws; do not reseed the reference and calibration
banks to the same seed.

The lower-level functions `HMM_lag_embed`, `HMM_interval_score`,
`HMM_scan_intervals`, `HMM_interval_penalty`, and `HMM_select_intervals` can also
be used separately. `HMM_interval_score` expects already whitened history rows.
The other scan/detection functions take unwhitened normal forecast residuals.

## Boundaries and lag histories

The package omits the first forecast residual: residual position 1 corresponds to
observation 2. `HMM_interval_residuals` returns `observation_indices` and the usable
segments in residual coordinates. `keep_last=false` also omits the last forecast,
matching the existing residual API. Filtering uses the complete observation
sequence, including observations outside monitored segments; segment boundaries
restrict the interval search and history construction, without restarting the HMM.

Every candidate `[a,b]` has inclusive **residual** endpoints and original length
`ell=b-a+1`. All starts are enumerated for every prespecified length, entirely
inside one segment. For lag order `q`, histories are stacked oldest first,
`[z[t-q+1,:]; ...; z[t,:]]`. Only histories wholly inside the candidate contribute:
their ending positions are `a+q-1:b`, so the scored sample size is
`n_I=ell-q+1`. This preserves the research implementation's boundary convention;
histories before the candidate are not borrowed. Lengths must be at least `q`.
For `q=1`, `n_I=ell`, exactly as in the manuscript's primary formulas.

The simulated common reference is estimated at the same lag order `q`. If
`Sigma0=L0*L0'`, each history is transformed by `L0 \ (history-mu0)`. For each
candidate, the local covariance `S_I` uses divisor `n_I`, matching the research
code's Gaussian moment calculation. With `d=p*q`,

```text
gamma_I = d/(n_I+d)
V_I = (1-gamma_I)*S_I + gamma_I*I_d
G_mean = n_I*dot(mean_I,mean_I)
G_cov  = n_I*(tr(V_I)-d-logdet(V_I))
G(I)   = G_mean + G_cov
```

Only negligible negative floating-point roundoff in the nonnegative covariance
component is floored at zero. Non-finite usable residuals and non-positive-definite
reference covariance are errors. No extra ridge, residual clipping, or reference
estimated from the observed trip is introduced. The reference and calibration
pipelines simulate complete observed response vectors; a design's segments specify
which positions are searched, rather than a per-channel missing-data mechanism.

## Calibration and interval selection

Each calibration replicate records one maximum `M_b` over all candidates. The
empirical upper quantile uses the research code's conservative finite-rank
convention: sort maxima descending and use order statistic
`floor(alpha*(B+1)-1)+1`. Eligibility is strictly `G > penalty`, excluding ties at
the cutoff. This is equivalent to requiring the whole-search Monte Carlo value
`(1+count(M_b >= G))/(B+1) <= alpha`. For `B=1999` and `alpha=0.05`, the cutoff is
the 100th largest maximum, with p-value resolution `1/2000`. No interpolation,
pilot tail transformation, score-based observed-trip tuning, or penalty multiplier
is used. If the bank cannot resolve the requested level, the penalty is infinite.
An empty candidate search also returns an infinite penalty and no episodes.

Dynamic programming with backtracking maximizes `sum(G(I)-penalty)` over
non-overlapping candidates. The empty collection is allowed. Adjacent intervals
can both be selected: `previous.stop < next.start` is sufficient, and there is no
minimum separation. Ties within relative tolerance `1e-12` follow the research
code: fewer intervals, larger total raw score, then lexicographically earlier
endpoints. The detector imposes no episode count and does not merge or extend
selected boundaries afterwards.

## Outputs

`detected.intervals` contains residual and observation boundaries, original
length, embedded row count, dimension, shrinkage, `G`, `G_mean`, `G_cov`, utility,
and whole-search Monte Carlo p-value. It also includes the whitened local mean,
covariance, and regularized covariance. `detected.candidates` retains every scanned
candidate with its score components; `selected_rows` maps back to that table.
`objective` is the total selected utility. The calibration object retains all
simulated maxima and the design; the reference result records the sampled design
indices and pooled history count.

With the calibration overload, `observation_start=start+1` and
`observation_stop=stop+1`. Use those bounds to retrieve episode cores in the
original observations. Duration in physical units depends on the caller's
monitoring convention; the detector returns counts and does not hard-code Hertz
or convert inclusive endpoints to seconds.

## Integration with the public package

`src/HMMToolkit.jl` includes the two interval source files and exports their three
types and nine functions. The detector uses the existing package dependencies,
emission precomputations, forecast-residual routines, and expert samplers. Existing
HMM APIs and the residual regression tests remain available.

The example and test runner default `HMMTOOLKIT_SKIP_PLOTS` to `true`. Set this
environment variable before loading HMMToolkit for headless numerical work.
Ordinary package loading retains its plotting import unless the variable is set;
plotting is not required by any detector function.

Episode characterization is a separate future component; see
[episode-characterization.md](episode-characterization.md).
